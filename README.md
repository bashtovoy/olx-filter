# OLX Фільтр

Розширення для Firefox і Chrome (Chromium), яке прибирає «ТОП» і зайві блоки з видачі OLX.ua, а також допомагає виставити сортування, ціну, стан і вигляд списку. Усі налаштування — у попапі розширення, а не на сторінці.

## Що вміє

- **Приховує ТОП** — за даними самої OLX (`isHighlighted`, `promotion.top_ad`), а не лише за видимим бейджем. Тому приховуються й ті ТОП-оголошення, у яких бейдж не відмальований.
- **Опційно приховує іншу рекламу** — окремий перемикач, типово вимкнений.
- **Чиста видача** — прибирає рекламні слоти `qa-advert-slot`, блок «Зберегти параметри пошуку» та SEO-блоки «Популярні запити» / текст під пагінацією. Увімкнено за замовчуванням; вимикається одним перемикачем.
- **Сортування** — «Спочатку дешеві», «Спочатку дорогі», «Спочатку нові», «Рекомендовані» або «Не змінювати».
- **Вигляд видачі** — «Плитка» або «Список» (`view=grid` / `view=list`).
- **Ціна** — діапазон «від / до» у валюті поточної сторінки.
- **Стан** — «Нове» / «Вживане». Якщо вибрано лише одне — додається фільтр OLX; якщо обидва або жодного — фільтр не встановлюється.
- **Приховувати «Обмін»** — опційно прибирає оголошення з ціною «Обмін» / «Обмен». Типово вимкнено, бо під час сортування «Спочатку дешеві» такі оголошення стоять першими, і з увімкненим перемикачем видача може стати порожньою.
- **Автозастосування** — якщо в URL ще немає сортування, вигляду, ціни або стану, розширення додає збережені налаштування під час відкриття сторінки видачі. Уже виставлені вручну фільтри OLX не перезаписуються.
- **Скидання фільтрів** — повертає сортування «Спочатку дешеві» і вигляд «Плитка», очищає ціну й стан, прибирає `page`.
- Налаштування зберігаються в `browser.storage.local` / `chrome.storage.local` і переживають перезавантаження.
- Попап типово українською; для браузерів із російською локаллю — російською.

## Встановлення

### Chrome / Chromium

1. Зберіть розпаковану Chrome-збірку:
   ```bash
   node scripts/build-chrome.mjs
   ```
2. Відкрийте `chrome://extensions` і увімкніть **«Режим розробника»**.
3. Натисніть **«Завантажити розпаковане розширення»** і виберіть теку `dist/chrome`.
4. Для окремого профілю запустіть Chrome з іншим `--user-data-dir`, потім завантажте `dist/chrome` у ньому:
   ```bash
   open -na "Google Chrome" --args \
     --user-data-dir="$TMPDIR/olx-chrome-profile" \
     --no-first-run
   ```

`dist/chrome` уже лежить у репозиторії. Після зміни вихідних файлів його потрібно перезібрати командою вище. Chrome-збірка потребує Chrome/Chromium **111+**.

Прапорець `--load-extension` у стабільному Google Chrome може бути недоступним. Для автоматизованих тестів використовуйте Chrome for Testing або Chromium з окремим профілем.

### Firefox: тимчасово, через about:debugging

1. Відкрийте `about:debugging#/runtime/this-firefox`.
2. Натисніть **«Load Temporary Add-on…»**.
3. Виберіть файл `manifest.json` із цієї теки.
4. Закріпіть кнопку розширення на панелі Firefox, щоб попап був під рукою.

Після перезапуску Firefox тимчасове розширення потрібно завантажити знову.

### Firefox: web-ext

```bash
web-ext run --source-dir .
```

### Firefox: постійне встановлення

Для постійного встановлення у звичайному Firefox розширення має бути підписане в AMO. Для локальної розробки можна використовувати Firefox Developer Edition/Nightly з вимкненою перевіркою підпису (`xpinstall.signatures.required = false`) і зібрати `.xpi` з теки.

## Chrome-збірка

`dist/chrome` — готова розпакована MV3-збірка. Вихідні файли спільні; `scripts/build-chrome.mjs`:

- копіює `common.js`, `content.js`, попап та іконки;
- прибирає Firefox-поле `browser_specific_settings`;
- додає `page-bridge.js` як content script у `world: "MAIN"`;
- виставляє `minimum_chrome_version: "111"`;
- перевіряє синтаксис JS і перестворює теку з нуля.

У Chrome ізольований content script не бачить React fiber сторінки, тому bridge винесено в MAIN world. Content script знаходить `page-bridge.js` у маніфесті й не вставляє inline-скрипт, тому CSP сторінки не порушується. У Firefox bridge, як і раніше, впроваджується inline з `content.js`. Після зміни `content.js` перезберіть `dist/chrome`.

Звіт про live-перевірку Chrome-збірки: [TESTING.md](TESTING.md).

## Як користуватися

1. Відкрийте будь-яку сторінку видачі OLX.ua, наприклад:
   `https://www.olx.ua/uk/elektronika/telefony-i-aksesuary/mobilnye-telefony-smartfony/`
2. Натисніть на іконку **«OLX Фільтр»** на панелі браузера.
3. Перемикачі «Приховувати ТОП», «Приховувати рекламу», «Приховувати «Обмін»» і «Чиста видача» спрацьовують одразу, без перезавантаження.
4. Сортування, вигляд, ціну й стан виберіть у попапі та натисніть **«Застосувати»**. Якщо змінилися сортування/вигляд/ціна/стан, сторінка OLX оновиться з новими параметрами.
5. **«Скинути фільтри»** повертає сортування «Спочатку дешеві», вигляд «Плитка» й очищає ціну/стан. Перемикачі відображення при цьому зберігаються.

На сторінці більше немає вбудованої панелі — її повністю замінено попапом.

## Важливі нюанси OLX

- На сторінці за замовчуванням (сортування «Рекомендовані») ТОП-оголошень може бути дуже багато. У перевірці на 19.10.2026 було **45–50 ТОП із 52** карток. Із сортуванням «Спочатку дешеві» — близько **14 із 51**. Тому після ввімкнення фільтра видача може помітно скоротитися — це очікувано.
- Під час сортування «Спочатку дешеві» OLX ставить першими оголошення з ціною **«Обмін»**, бо для сортування вони вважаються нульовою ціною. Їх можна приховати перемикачем «Приховувати «Обмін»» або вказати мінімальну ціну, наприклад `1` чи `1000` грн.
- Ціна зберігається разом із валютою сторінки (`UAH`, `USD`, `EUR`). Якщо відкрити сторінку в іншій валюті, попап не підставить старий діапазон і покаже попередження.
- «Чиста видача» приховує рекламні комірки та SEO-блоки, але не видаляє їх із DOM. Якщо OLX змінить `data-testid`, список блоків, що приховуються, потрібно оновити в `content.js`.
- Розширення працює на `www.olx.ua` і `olx.ua`. Це десктопна версія сайту.
- OLX може змінювати розмітку й назви параметрів. Усі ключові селектори та URL-параметри зібрані в `common.js` і `content.js`.

## Як це працює

1. Під час завантаження сторінки content script намагається зловити `window.__PRERENDERED_STATE__` з `#olx-init-config` до того, як React видалить цей скрипт.
2. Додатково у сторінку впроваджується невеликий bridge-скрипт. Він читає стан із SSR та/або знаходить масив оголошень у React fiber. У Chrome цей bridge збирається як окремий `page-bridge.js` у MAIN world і підключається маніфестом; inline-вставка там не використовується.
3. З оголошень беруться ID з `isHighlighted` / `promotion.top_ad` (ТОП) і `isPromoted` / `searchReason=promoted` (реклама).
4. Для приховування використовується CSS за ID карток + клас на картці. Це не видаляє оголошення з DOM і не ламає пагінацію.
5. «Чиста видача» додає CSS-стилі для рекламних слотів і позначає контейнери «Зберегти пошук» та SEO-блоків класом `olxf-junk`.
6. Попап читає поточні параметри з URL, зберігає налаштування в `browser.storage.local` / `chrome.storage.local` і застосовує сортування/вигляд/ціну/стан через параметри URL OLX.
7. Під час клієнтської зміни сторінки OLX bridge повторно читає fiber і оновлює список прихованих ID.
8. Усі налаштування зберігаються локально. Розширення не надсилає дані на сторонні сервери.

## Структура

```text
manifest.json          — маніфест Firefox MV3
common.js              — налаштування за замовчуванням і робота з URL-параметрами OLX
content.js             — читання SSR/fiber, приховування карток і «сміття», автозастосування
popup.html             — розмітка попапа
popup.css              — стилі попапа
popup.js               — логіка попапа, збереження налаштувань, застосування до активної вкладки
scripts/build-chrome.mjs — збірка Chrome-версії
dist/chrome/           — готова Chrome MV3-збірка (включно зі згенерованим page-bridge.js)
icons/                 — іконки розширення (16/32/48/96) і SVG-джерело
README.md              — цей файл
TESTING.md             — звіт про live-перевірку Chrome-збірки
LICENSE                — ліцензія MIT
```

## Обмеження

- Тимчасове розширення зникає після перезапуску Firefox — це обмеження `about:debugging`, а не розширення.
- Chrome-збірка потребує Chrome/Chromium 111+ і підтримує `www.olx.ua` і `olx.ua`.
- `dist/chrome` — згенерована тека. Після зміни вихідних файлів її потрібно перезібрати, інакше Chrome завантажить стару версію.
- «Чиста видача» спирається на поточні `data-testid` OLX. Після серйозного редизайну сайту селектори доведеться оновити.
- Розширення не обходить CAPTCHA, не змінює роботу самої OLX і не надсилає запити від вашого імені.
- Якщо OLX повністю перемалює структуру стану, потрібно буде оновити селектори/шляхи в `content.js`.
