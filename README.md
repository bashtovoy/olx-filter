# OLX Фільтр

Расширение для Firefox и Chrome (Chromium), которое убирает «ТОП» и лишние блоки из выдачи OLX.ua, а также помогает выставить сортировку, цену, состояние и вид списка. Все настройки находятся в попапе расширения, а не на странице.

## Что умеет

- **Скрывает ТОП** — по данным самой OLX (`isHighlighted`, `promotion.top_ad`), а не только по видимому бейджу. Поэтому скрываются и те ТОП-объявления, у которых бейдж не отрисован.
- **Опционально скрывает остальную рекламу** — отдельный переключатель, по умолчанию выключен.
- **Чистая выдача** — убирает рекламные слоты `qa-advert-slot`, блок «Зберегти параметри пошуку» и SEO-блоки «Популярні запити» / текст под пагинацией. Включено по умолчанию; отключается одним переключателем.
- **Сортировка** — «Сначала дешёвые», «Сначала дорогие», «Сначала новые», «Рекомендованные» или «Не менять».
- **Вид выдачи** — «Плитка» или «Список» (`view=grid` / `view=list`).
- **Цена** — диапазон «от / до» в валюте текущей страницы.
- **Состояние** — «Новое» / «Б/у». Если выбрано только одно — добавляется фильтр OLX; если оба или ни одного — фильтр не ставится.
- **Скрывать «Обмен»** — опционально убирает объявления с ценой «Обмін» / «Обмен». По умолчанию выключено, потому что при сортировке «Сначала дешёвые» такие объявления стоят первыми, и при включении выдача может стать пустой.
- **Автоприменение** — если в URL ещё нет сортировки, вида, цены или состояния, расширение добавляет сохранённые настройки при открытии страницы выдачи. Уже выставленные вручную фильтры OLX не перезаписываются.
- **Сброс фильтров** — возвращает сортировку «Сначала дешёвые» и вид «Плитка», очищает цену и состояние, убирает `page`.
- Настройки сохраняются в `browser.storage.local` / `chrome.storage.local` и переживают перезагрузку.
- Попап автоматически переключается между русским и украинским языком по языку браузера.

## Установка

### Chrome / Chromium

1. Соберите распакованную Chrome-сборку:
   ```bash
   node scripts/build-chrome.mjs
   ```
2. Откройте `chrome://extensions` и включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `dist/chrome`.
4. Для отдельного профиля запустите Chrome с другим `--user-data-dir`, затем загрузите `dist/chrome` в нём:
   ```bash
   open -na "Google Chrome" --args \
     --user-data-dir="$TMPDIR/olx-chrome-profile" \
     --no-first-run
   ```

`dist/chrome` уже лежит в репозитории. После изменения исходников его нужно пересобрать командой выше. Chrome-сборка требует Chrome/Chromium **111+**.

Флаг `--load-extension` в стабильном Google Chrome может быть недоступен. Для автоматизированных тестов используйте Chrome for Testing или Chromium с отдельным профилем.

### Firefox: временно, через about:debugging

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Load Temporary Add-on…»**.
3. Выберите файл `manifest.json` из этой папки.
4. Закрепите кнопку расширения на панели Firefox, чтобы попап был под рукой.

После перезапуска Firefox временное расширение нужно загрузить снова.

### Firefox: web-ext

```bash
web-ext run --source-dir .
```

### Firefox: постоянная установка

Для постоянной установки в обычном Firefox расширение должно быть подписано в AMO. Для локальной разработки можно использовать Firefox Developer Edition/Nightly с отключённой проверкой подписи (`xpinstall.signatures.required = false`) и собрать `.xpi` из папки.

## Chrome-сборка

`dist/chrome` — готовая распакованная MV3-сборка. Исходники общие; `scripts/build-chrome.mjs`:

- копирует `common.js`, `content.js`, попап и иконки;
- убирает Firefox-поле `browser_specific_settings`;
- добавляет `page-bridge.js` как content script в `world: "MAIN"`;
- выставляет `minimum_chrome_version: "111"`;
- проверяет синтаксис JS и пересоздаёт папку с нуля.

В Chrome изолированный content script не видит React fiber страницы, поэтому bridge вынесен в MAIN world. В Firefox bridge по-прежнему внедряется inline из `content.js`. После изменения `content.js` пересоберите `dist/chrome`.

Отчёт о live-проверке Chrome-сборки: [TESTING.md](TESTING.md).

## Как пользоваться

1. Откройте любую страницу выдачи OLX.ua, например:
   `https://www.olx.ua/uk/elektronika/telefony-i-aksesuary/mobilnye-telefony-smartfony/`
2. Нажмите на иконку **«OLX Фільтр»** на панели браузера.
3. Переключатели «Скрывать ТОП», «Скрывать рекламу», «Скрывать «Обмен»» и «Чистая выдача» срабатывают сразу, без перезагрузки.
4. Сортировку, вид, цену и состояние выберите в попапе и нажмите **«Применить»**. Если поменялись сортировка/вид/цена/состояние, страница OLX обновится с новыми параметрами.
5. **«Сбросить фильтры»** возвращает сортировку «Сначала дешёвые», вид «Плитка» и очищает цену/состояние. Переключатели отображения при этом сохраняются.

На странице больше нет встроенной панели — она полностью заменена попапом.

## Важные нюансы OLX

- На странице по умолчанию (сортировка «Рекомендованные») ТОП-объявлений может быть очень много. В проверке на 19.10.2026 было **45–50 ТОП из 52** карточек. С сортировкой «Сначала дешёвые» — около **14 из 51**. Поэтому после включения фильтра выдача может заметно сократиться — это ожидаемо.
- При сортировке «Сначала дешёвые» OLX ставит первыми объявления с ценой **«Обмін»**, потому что для сортировки они считаются нулевой ценой. Их можно скрыть переключателем «Скрывать «Обмен»» или указать минимальную цену, например `1` или `1000` грн.
- Цена сохраняется вместе с валютой страницы (`UAH`, `USD`, `EUR`). Если открыть страницу в другой валюте, попап не подставит старый диапазон и покажет предупреждение.
- «Чистая выдача» скрывает рекламные ячейки и SEO-блоки, но не удаляет их из DOM. Если OLX изменит `data-testid`, список скрываемых блоков нужно обновить в `content.js`.
- Расширение работает на `www.olx.ua` и `olx.ua`. Это десктопная версия сайта.
- OLX может менять разметку и названия параметров. Все ключевые селекторы и URL-параметры собраны в `common.js` и `content.js`.

## Как это работает

1. При загрузке страницы content script пытается поймать `window.__PRERENDERED_STATE__` из `#olx-init-config` до того, как React удалит этот скрипт.
2. Дополнительно в страницу внедряется небольшой bridge-скрипт. Он читает состояние из SSR и/или находит массив объявлений в React fiber. В Chrome этот bridge собирается как отдельный `page-bridge.js` в MAIN world.
3. Из объявлений берутся ID с `isHighlighted` / `promotion.top_ad` (ТОП) и `isPromoted` / `searchReason=promoted` (реклама).
4. Для скрытия используется CSS по ID карточек + класс на карточке. Это не удаляет объявления из DOM и не ломает пагинацию.
5. «Чистая выдача» добавляет CSS-стили для рекламных слотов и помечает контейнеры «Сохранить поиск» и SEO-блоков классом `olxf-junk`.
6. Попап читает текущие параметры из URL, сохраняет настройки в `browser.storage.local` / `chrome.storage.local` и применяет сортировку/вид/цену/состояние через параметры URL OLX.
7. При клиентской смене страницы OLX bridge повторно читает fiber и обновляет список скрытых ID.
8. Все настройки хранятся локально. Расширение не отправляет данные на сторонние серверы.

## Структура

```text
manifest.json          — манифест Firefox MV3
common.js              — настройки по умолчанию и работа с URL-параметрами OLX
content.js             — чтение SSR/fiber, скрытие карточек и «мусора», автоприменение
popup.html             — разметка попапа
popup.css              — стили попапа
popup.js               — логика попапа, хранение настроек, применение к активной вкладке
scripts/build-chrome.mjs — сборка Chrome-версии
dist/chrome/           — готовая Chrome MV3-сборка (включая сгенерированный page-bridge.js)
icons/                 — иконки расширения (16/32/48/96) и SVG-исходник
README.md              — этот файл
TESTING.md             — отчёт о live-проверке Chrome-сборки
```

## Ограничения

- Временное расширение исчезает после перезапуска Firefox — это ограничение `about:debugging`, а не расширения.
- Chrome-сборка требует Chrome/Chromium 111+ и поддерживает `www.olx.ua` и `olx.ua`.
- `dist/chrome` — сгенерированная папка. После изменения исходников её нужно пересобрать, иначе Chrome загрузит старую версию.
- «Чистая выдача» опирается на текущие `data-testid` OLX. При серьёзном редизайне сайта селекторы придётся обновить.
- Расширение не обходит CAPTCHA, не меняет работу самой OLX и не отправляет запросы от вашего имени.
- Если OLX полностью перерисует структуру состояния, потребуется обновить селекторы/пути в `content.js`.
