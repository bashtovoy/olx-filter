# Перевірка Chrome-збірки

Дата перевірки: 19.10.2026.

Збірка: `dist/chrome` (Chrome MV3).

Браузер: Google Chrome for Testing `153.0.8010.12` з окремим профілем
`$TMPDIR/olx-chrome-profile`. Розширення завантажено через `--load-extension` і
`--disable-extensions-except`; MCP-сервер `chrome-devtools-mcp 1.11.0`
підключено до `http://127.0.0.1:9223`.

Примітка: перевірки виконувалися на версії 0.2.0 до перекладу інтерфейсу.
У 0.2.1 типовою мовою попапа є українська (російська — для `ru-*` локалей);
функціональність не змінювалася. Цитати статусів у звіті перекладено
українською.

## Збірка та завантаження

- `node scripts/build-chrome.mjs` — успішно.
- `node --check` для `common.js`, `content.js`, `page-bridge.js`, `popup.js` — успішно.
- `manifest.json` у `dist/chrome` — валідний JSON, без `browser_specific_settings`,
  з `minimum_chrome_version: "111"`.
- Розширення з'явилося в `chrome://extensions` і в списку розширень Chrome DevTools MCP.
- `page-bridge.js` працює в MAIN world: React fiber доступний, помилок CSP немає.

## Живі перевірки на OLX.ua

Перевірки виконувалися на реальних сторінках `www.olx.ua`; для `olx.ua` сайт
перенаправляє на `www.olx.ua`, content script при цьому працює.

### CSP і bridge

Причина помилки: Chrome content script викликав legacy `injectBridge()`, який
вставляв inline `<script>`. На сторінці зі строгою CSP callback Chrome блокував
його повідомленням `Executing inline script violates ...` і вказував на
`content.js` / `injectBridge`.

Виправлення: content script знаходить `page-bridge.js` у
`runtime.getManifest().content_scripts` і не виконує inline-вставку. У Chrome
bridge вже підключено маніфестом у `world: "MAIN"`; шлях Firefox з inline bridge
не змінено. Chrome теж надає об'єкт `browser`, тому перевірка за наявністю
`chrome`/`browser` ненадійна — джерело істини саме маніфест.

Перевірка на реальному callback URL
`https://www.olx.ua/d/uk/callback/?code=…&state=…`:

- до редиректу на головну в DOM встигли з'явитися `#olxf-base-style` і
  `#olxf-clean-style` — content script на callback-сторінці справді
  виконався;
- MutationObserver не зафіксував жодної вставки inline `<script>` з bridge:
  `0`;
- після завантаження `inlineBridgeScripts = 0`;
- `window.__olxFilterBridgeInstalled = true` — MAIN-world bridge працює;
- у консолі немає `Executing inline script violates ...` і немає помилок
  `content.js:... (injectBridge)`;
- залишилася лише незалежна помилка в консолі самої OLX: браузер блокує
  `data:video/mp4` за її CSP `default-src 'self' *`. До розширення вона не
  стосується.

Повторна перевірка звичайної видачі після цієї ж збірки:

- 52 картки, 39 видимих, 13 прихованих (13 ТОП);
- 0 видимих бейджів «ТОП», 0 видимих рекламних слотів;
- 4 колонки в плитці;
- `inlineBridgeScripts = 0`, `window.__olxFilterBridgeInstalled = true`.

Перемикач «Приховувати ТОП» у попапі:

- вимкнено: 52 видимих / 0 прихованих, статус `Приховано: 15 блоків`;
- увімкнено: 39 видимих / 13 прихованих, статус `Приховано: 13 ТОП · 15 блоків`;
- зміни застосовуються одразу, без перезавантаження сторінки.

### Приховування ТОП і реклами

- Електроніка, сортування «Спочатку дешеві», плитка:
  - 51 картка, 14 приховано, 37 видно;
  - 0 видимих бейджів «ТОП»;
  - 13 рекламних слотів, 0 видимих;
  - блоки «Зберегти пошук» і SEO приховані.
- Електроніка без параметрів, сортування за замовчуванням:
  - 50 ТОП із 52 карток було приховано до автозастосування фільтрів;
  - після автозастосування — 14 ТОП і 36–37 видимих карток.
- «Приховувати рекламу»:
  - при вимкненому ТОП приховано 38 карток, 0 видимих промо-посилань;
  - при увімкненому ТОП додаткових змін немає, якщо всі промо-картки
    вже входять до ТОП.
- «Приховувати «Обмін»» на видачі «Спочатку дешеві»:
  - 22 картки з ціною «Обмін» приховано, 0 видимих;
  - статус: `14 ТОП · 22 обмін · 15 блоків`.

### Вигляд видачі

- `view=grid` — 4 колонки, ширина карток близько 295.5 px.
- `view=list` — одна колонка шириною близько 1029 px.

### Фільтри через попап

Застосування налаштувань: сортування «Спочатку дорогі», вигляд «Список», ціна
`1000–5000`, стан «Вживане».

Підсумковий URL:

```text
https://www.olx.ua/uk/elektronika/?search%5Bfilter_enum_state%5D%5B0%5D=used&search%5Bfilter_float_price%3Afrom%5D=1000&search%5Bfilter_float_price%3Ato%5D=5000&search%5Border%5D=filter_float_price%3Adesc&view=list
```

Результат: 52 картки, 36 видимих, 16 прихованих, вигляд «Список», ціни в діапазоні
1000–5000, стан «Вживане».

- «Скинути фільтри» повернув `search[order]=filter_float_price:asc&view=grid`,
  очистив ціну й стан, повернув 4 колонки.
- Невалідний діапазон `5000–1000`: показано помилку
  «Мінімальна ціна більша за максимальну», URL не змінився.
- Автозастосування увімкнено: нова сторінка без параметрів отримала сортування,
  вигляд, ціну й стан із збережених налаштувань.
- Автозастосування вимкнено: нова сторінка відкрилася без доданих параметрів.
- Перезавантаження попапа зберегло всі значення з `chrome.storage.local`.
- Пагінація `page=2` збереглася разом із `search[order]` і `view`.

### Стани попапа

- На `about:blank`: «Відкрийте сторінку OLX.ua».
- На головній OLX: «Відкрийте результати пошуку OLX».
- На сторінці видачі: коректний лічильник прихованих елементів.

## Помилки

Після CSP-фіксу на перевірених сторінках розширення й попапа немає console
errors/warnings, пов'язаних із розширенням. Зокрема, більше немає
`Executing inline script violates ...` і помилок `content.js:... (injectBridge)`.

На OLX залишається незалежна помилка в консолі: браузер блокує `data:video/mp4`
самої OLX за її CSP `default-src 'self' *`. Вона не пов'язана з розширенням.
Мережеві помилки рекламних iframe OLX також до розширення не належать.

## Обмеження

У стабільному Google Chrome прапорець `--load-extension` може бути вимкнений. Для
автоматизованих тестів використовувався Chrome for Testing; для звичайного
встановлення — завантаження розпакованої теки `dist/chrome` через
`chrome://extensions`.
